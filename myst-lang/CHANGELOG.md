# Change Log

All notable changes to the "myst-lang" extension will be documented in this file.

## [Unreleased]

### Added

- Comprehensive TextMate grammar support for the Myst language (`.ms`, `.myst`).
- Syntax highlighting for control flow and definition keywords (`func`, `var`, `if`, `elseif`, `else`, `while`, `for`, `break`, `return`, `and`, `or`, `not`).
- Highlighting for primitive types (`char`, `int`, `decimal`, `bool`).
- Support for line comments starting with `\\`.
- Dedicated syntax rules for character literals (e.g., `'a'`, `'\n'`).
- Enhanced string literal highlighting with support for escape sequences.
- Highlighting for numeric literals (integers and decimals) and boolean constants (`true`, `false`).
- Full operator support including arithmetic, comparison, and logical operators.
